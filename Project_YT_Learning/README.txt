YouTube Knowledge & Investment Immersion — Extension 0.3.1.0

本版重點
1. 開啟 YouTube 影片後，自動偵測影片 ID，嘗試開啟原生「顯示轉錄稿」面板並讀取字幕行。
2. 以 YouTube 面板顯示的時間戳與文字建立完整逐字稿資料。
3. 保留可見字幕即時觀察，但與完整逐字稿分開儲存。
4. 合併即時字幕的重複觀察與逐步累積文字。
5. 手動貼上備援解析：支援 YouTube 複製格式（例如 3:103 分 10 秒字幕文字）、SRT、VTT、時間戳前綴純文字。
6. JSON 匯出包含 transcript 與 liveObservations 兩個獨立欄位。

安裝 / 更新
- 建議先備份 0.2 的資料與資料夾。
- 解壓縮本 ZIP。
- 為盡量保留 Chrome Extension ID 及既有 chrome.storage.local，請將本版檔案覆蓋到原本 0.2「載入未封裝項目」所使用的同一個資料夾路徑，再到 chrome://extensions 按該 Extension 的「重新載入」。
- 若改用新資料夾載入，Chrome 可能給不同 Extension ID，舊版本機儲存資料不會自動搬移。
- 若不想覆蓋，先停用 0.2，再以新資料夾載入 0.3；不要刪除舊資料夾。

使用與測試
- 開啟有字幕的 YouTube 影片，等待約數秒，側邊欄應顯示自動擷取狀態與段落數。
- 測試創作者字幕、自動生成字幕、日文字幕、長影片、影片 A/B/A 切換。
- 「重新檢查逐字稿」只作為測試/失敗重試入口；正常流程不需要按它。
- 若自動擷取失敗，請先確認 YouTube 影片本身有「顯示轉錄稿」功能，再匯出 JSON 或回報側邊欄狀態。
- 可用手動貼上作為備援；YouTube 複製格式會依第一個 m:ss 時間戳解析，丟棄後方重複的本地化時間標籤。

重要限制
- 自動擷取依賴 YouTube 當前頁面 DOM，YouTube 改版可能導致選擇器失效。
- 此版本讀取的是 YouTube 逐字稿面板實際渲染的行；會嘗試捲動面板載入更多行，但「讀取到的段落數」不等於已證明完整。請用影片末段時間戳與 YouTube 原生逐字稿比對。
- 若影片沒有可用字幕，原生逐字稿不存在，這版不會自行執行 ASR。
- 這是技術原型，不代表已完成 YouTube 條款、商用權利或隱私法遵審查。
- 本版沒有外部網路請求、沒有 AI API、沒有後端；字幕資料保存在本機 Chrome Storage。
