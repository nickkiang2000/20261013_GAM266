# PTT／PTT2 文章下載與離線閱讀

雙擊 `start.bat` 開啟本機頁面。選擇 PTT 或 PTT2，輸入該站的帳密、可閱讀的板名和備份資料夾。第一次使用 PTT 時先保留起始編號 0、篇數 5，核對文章再擴到 20 和 200 篇。起始編號 0 會選取最新幾個編號。要從最舊開始請填 1。

已安裝依賴於專案 .venv。若移動到別台電腦，需 Python 3.12，執行 `python -m venv .venv` 及 `.venv\Scripts\python -m pip install -r requirements.txt`。

不會寫入密碼或輸出 SDK 日誌；不會踢除其他登入連線。每次任務登入一次，遇錯即停止，不密集重試。二階段驗證尚未提供接續 UI，遇到會停止。此版不是完整互動終端機。

下載時逐篇寫入 `articles.sqlite3`，以站台、看板和 AID 識別文章。重跑會重新查 AID，跳過同站同板已保存的文章。中斷後請手動登入重跑。資料庫的 `failures` 表記錄未取得 AID 或錯誤類別。

匯出會在備份資料夾建立 `index.html` 和 `articles/`。每篇文章有一個可獨立開啟的 HTML 檔。移動備份時，將索引和 `articles/` 一起移動，便可保留相對連結。索引從最新一頁開始，每頁最多 20 篇，舊文在上、新文在下。開啟索引時會選中第一個看板的最新一篇。按 ↑／↓ 選文，跨頁時會自動翻頁。Page Up／Page Down 切換較舊或較新的一頁，Enter 或 → 開啟文章。閱讀中按 ↓ 向下捲動一行，捲到底後再按 ↓ 開啟較新一篇。→ 向下翻一整頁，翻到底後再按 → 返回文章列表。↑ 開啟較舊一篇，← 或 Esc 返回該篇在列表的位置。使用 Page Up／Page Down 可捲動長文。

舊版 PTT2 備份可直接轉換。填入放有 `articles.sqlite3` 的資料夾，點「匯出既有備份」，無需登入。程式會把舊資料庫中的文章標為 PTT2，並更新該資料夾的 `index.html`。

全板一般文章可設起始編號 1、掃描數量 10000，實際上限取站上當時最大編號。篇數和最大編號可能不同。置底文盤點、精華區與全量一致性對帳仍待完成。

此版本使用 PyPtt WSS。文字與推文保留 SDK 回傳的全文和 JSON。指定文章測試會擷取可對上正文的 ANSI 配色，未對上的行保留純文字。批次下載可選擇啟用配色擷取。舊純文字備份需重新讀取才能取得色碼。SSH 待實作。

ANSI 試跑請選 PTT、板名 `NctuNthuTYSH`、AID `1AdzogFB`，並使用一個測試用備份資料夾。由本機登入後會只下載〈色碼教學〉一篇。狀態會列出對上終端畫面的行數及含色碼行數。開啟 `index.html` 比對標題圖和正文配色，通過後再擴到多篇。支援基本八色、亮色、反白與重設。雙色字、閃爍及進階色票尚待驗證。

2,218 篇全新文章的固定等待時間約 3 小時 5 分。實際時間還包含站台查詢、讀文、翻頁和匯出。下載狀態會顯示新文章的平均處理秒數，並依試跑結果估算 2,218 篇所需時間。

舊版 PTT2 小樣本已由使用者試跑。新版通過模擬 PTT 下載、舊資料遷移和單篇匯出測試。PTT 仍待用實際帳號試跑。
