# PTT2 文章下載測試版

雙擊 start.bat，以瀏覽器開啟本機介面。輸入帳密、可閱讀的板名和資料夾，先使用預設 5 篇測試。

已安裝依賴於專案 .venv。若移動到別台電腦，需 Python 3.12，執行 `python -m venv .venv` 及 `.venv\Scripts\python -m pip install -r requirements.txt`。

不會寫入密碼或輸出 SDK 日誌；不會踢除其他登入連線。每次任務登入一次，遇錯即停止，不密集重試。二階段驗證尚未提供接續 UI，遇到會停止。此版不是完整互動終端機。

下載結果在指定資料夾的 articles.sqlite3；結束後產生 index.html，可斷網閱讀。重跑會重新查 AID，跳過已儲存文章。沒有自動重連；手動登入重跑。failures 表記錄未取得 AID 或錯誤類別。

先核對 5 篇，再測 20／200 篇。全量可設起始編號 1、掃描數量 10000，實際上限取站上當時最大編號；6882 是預估文章數，不能當作固定最大編號。此版尚未另外遍歷置底、精華區，亦未完成全量一致性對帳，不應據此刪除任何來源資料。

此版本使用 PyPtt WSS，尚未加入 SSH。文字／推文保留 SDK 回傳全文與 JSON；不保證伺服器原始檔位元組一致或 ANSI 彩色還原。

驗證狀態：本機儲存與匯出可測；尚無帳號進行登入後實站下載驗證。請勿將「程式可啟動」視為「6882 篇可完整下載」。
