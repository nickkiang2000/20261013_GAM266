# PTT／PTT2／CCNS 文章下載與離線閱讀

目前版本為 **v2.28.8**。v2.1.0 之前的版本統稱 v1.x.x。

v2.28.6 優先修正 CCNS 單篇 q 查詢無法辨識就中止整批的問題。查詢完成提示與有效文章代碼分開辨識；未取得完整 8 碼代碼時記錄固定分類、代碼長度與安全代碼欄，不保存登入畫面或整頁列表。查詢異常、逾時或選取不符時，只有收到新的同看板列表核對成功才列待查繼續；同樣涵蓋續傳錨點查詢。未知確認畫面不盲目略過，真正連線中斷仍停止保留進度。這版不放寬正文配色、行號與首部核對，也不處理先前討論的介面改版。

v2.28.5 修正舊 CCNS 簽名尾端亮白反斜線沒有後續文字時被誤當折行：原樣保留字元、空白與配色，不再要求不存在的下一列。真正折行仍要求右側亮白標記、可見後續文字及來源行數吻合。首屏第 0～N 行可依可見列數核對為第一屏，其他頁不猜測 0 行。舊文末 99%→100% 即使尾行相同，只要已讀內容連續、文字配色一致且最後頁為 100%，仍可確認完成；不把 99% 當文末。十篇舊失敗畫面已完成保留頁面重播，第 6 篇另以公開 guest 實測完整 78%→99%→100%，不寫回正式備份。

v2.28.4 支援 CCNS 星號取代篇號的列表列：要求上下數字錨點推得相同篇號，再核對文章代碼；已下載並確認的星號文章於時光庫最新頁底部加列置底入口，保留原篇號及一般列表入口，不更動站上設定，也不宣稱已盤點全板置底。轉錄文章首部可保留來源看板，但須先完成讀前及讀後同一文章代碼、目的看板核對。亮白行尾反斜線只在右側位置、存在後續文字且重組符合來源行數時視為系統折行，保留一般反斜線。以已保存失敗畫面驗證五篇完整轉錄文及一篇前兩頁接合，仍需實站重新下載完成身分核對。

同步程式碼時可排除 `.venv` 和所有 `__pycache__`。`.venv` 是本機 Python 虛擬環境，套件升級或重建環境時才需要更新。`__pycache__` 是 Python 執行時自動產生的快取。新副本用 Python 3.12 執行 `python -m venv .venv` 及 `.venv\Scripts\python.exe -m pip install -r requirements.txt`，再雙擊 `start.bat`。下載的文章另放在指定的備份資料夾。若也要備份文章，等任務結束後複製該資料夾，包含 `articles.sqlite3`、`index.html` 和 `articles/`。
