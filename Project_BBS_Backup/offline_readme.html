操作教學（鍵盤操作）

文章列表
↑／↓ 選文，Enter 或 → 開啟。Page Up／Page Down 翻頁，Home／End 前往最舊／最新一篇。列表按編號 1～20、21～40 等固定範圍分頁，空範圍略過。開啟時選在最新一篇。
文章內
↓ 往下捲一行，讀到底後再按會開啟較新一篇。→ 往下移動 22 行，讀到底後再按會回到列表。↑ 開啟較舊一篇，← 或 Esc 返回列表原位置。可開啟「22 行視窗」逐頁閱讀。
