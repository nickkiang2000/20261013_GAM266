BBS 備份操作與色彩說明

下載範圍與資料夾

在「進階設定」中，起始編號填 0 時，選取最新的指定篇數。填 1 以上時，從該編號算起取指定範圍。掃描方向預設新到舊，可改成舊到新。離線列表一律是舊文在上、新文在下。填 AID 時只處理該篇。

可先在備份完整目錄輸入 D:\BBS_Backup\。站台 PTT、板名 YP91-304 的新備份會補成 D:\BBS_Backup\PTT_YP91-304\。已有同板資料庫的舊資料夾會沿用原位置。上次填寫的帳號、站台、板名、AID、範圍和目錄會存在本機設定，密碼每次由你輸入。

中斷後用同一站台、板名和備份位置重新登入，會沿用未完成的範圍與方向。若本次設定不同，開始前會顯示原批次與本次設定供選擇。另開新批次時，已保存的文章會保留。斷線後等網路恢復再登入，站方若提示暫停連線，請依提示等候。

下載與匯出進度

本地讀取
作業開始時，所選備份資料夾的資料庫已有的文章篇數。
網站掃描
已處理的網站項目數，包含讀取、比對、同批先前已核對和待查的項目。
無更新
本次已重讀並比對正文、推文和色碼，確認可保留原備份。
已更新
本次判定應寫入的篇數，包含新增、正文或配色有變化，以及可更新擷取結果的文章。
已存檔
本次成功寫入本機資料庫的篇數。離線 HTML 總數會另外顯示。
待查／待核對
文章待查包含查不到 AID、鎖定或正文格式未通過，這次未建立該篇。配色待核對表示正文仍可建立 HTML，未對上的部分以文字顯示。
已建立 HTML
下載結束或手動停止後，程式以資料庫建立單篇 HTML，含既有備份。完成後可點 index.html 路徑，由本機服務開啟。關閉工具後也可從檔案總管開啟同一份索引。

新批次會重讀所選範圍內的可讀文章，以收錄原作者編輯後的內容。首頁的「離線內容重整」用本機資料庫重新建立 HTML 和索引，可離線套用新版版面、更新鍵盤操作或補回遺失的 HTML。

每次下載的診斷紀錄集中在程式資料夾的 log 子目錄，依執行開始時間命名。紀錄包含階段、文章編號、可用時的 AID、錯誤類型和程式位置。密碼、正文、登入畫面和例外原文不寫進診斷檔。

離線鍵盤操作

列表每頁最多 20 篇，開啟後預設選在最新一篇。↑／↓ 選文，Enter 或 → 開啟，Page Up／Page Down 翻頁，Home／End 前往最舊／最新一篇。上方也有翻頁按鈕。

文章內 ↓ 往下捲一行，讀到底後再按會開啟較新一篇。→ 往下移動 22 行，讀到底後再按會回到列表。可開啟「22 行視窗」逐頁看手動翻頁的動畫。↑ 開啟較舊一篇，← 或 Esc 回到列表原位置。

ANSI 色彩怎麼轉成 HTML

程式在讀取文章時擷取終端前景色、背景色、亮色、反白和重設，逐行核對正文後用本機 CSS 顯示。游標跳過的空白維持背景色，文章刻意上色的空格會保留。未對上的行以文字顯示。雙色字、閃爍及進階色票仍有相容性限制。
