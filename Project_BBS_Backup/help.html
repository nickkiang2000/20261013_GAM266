BBS 備份操作說明與紀錄

各備份的錯漏紀錄請由該備份 index.html 右上角「操作說明與紀錄」開啟；本機控制頁的說明不含個別備份紀錄。舊備份可先執行「離線內容重整」，不需登入。

下載範圍與資料夾

起始編號就是第一個掃描的編號，填 0 時從站上最新一篇開始。預估下載範圍隨起始編號、篇數及方向更新。掃描篇數包含起始那篇，並受看板兩端限制。掃描方向預設新到舊，可改成舊到新。離線列表一律是舊文在上、新文在下。

可先在備份完整目錄輸入 D:\BBS_Backup\。站台 PTT、板名 YP91-304 的新備份會補成 D:\BBS_Backup\PTT_YP91-304\。已有同板資料庫的舊資料夾會沿用原位置。上次填寫的帳號、站台、板名、範圍和目錄會存在本機設定。指定文章 AID 和密碼由你輸入。

「登入新下載」使用目前表單設定，預設補齊備份。「補齊備份」查詢文章 AID 後沿用已有正文，只抓缺少的文章。「重新核對」重讀所選範圍，檢查正文、推文和配色有無更新。

「登入續傳」使用同一站台、板名與備份位置的未完成批次，保留範圍、方向及備份方式。按「登入新下載」會取代未完成批次。要由新到舊掃描整板，可將起始編號填 0，掃描篇數填入看板的最新文章編號。

測試一篇時，展開「單篇測試」，輸入 AID 並選擇擷取方式及終端高度，再按「登入並測試下載」。每次測試在程式資料夾的 test-downloads/ 產生獨立結果，可從下載狀態開啟。正式備份及其續傳進度照舊。

一般文章在同一連線內逐篇讀取。每實際處理 25 筆會休息 20 秒，再自動繼續同一批。站方顯示限速時，程式停止送鍵並在原連線等待恢復時間。若明確顯示看板暫時關閉，則等待 3 分鐘。到時確認看板畫面後再接續；斷線或畫面無法辨識時保存進度並通知。

登入新下載和登入續傳都使用自動擷取，手動選擇逐行或逐頁的選項在單篇測試。自動擷取在確認首屏就是末頁時直接使用同一個畫面，多頁文章則使用 Page Down 核對接縫和末頁。若無法核對但已安全返回看板，只對該篇改用逐行重讀一次。單篇測試的逐頁選項會直接呈現逐頁的成功或待查結果。

逐行模式若文章行號停住但未顯示 100%，程式會核對行號是否完整，並嘗試往前移一行後用 End 回到同一末頁。必要時用 24 列終端重讀一次。仍無法確認全文時，若可安全返回列表，該篇列為待查，其餘文章繼續處理。指定 AID 時也可勾選「24 列相容讀取」，這次單篇會從登入起使用 24 列。

下載與匯出進度

本地讀取
作業開始時，所選備份資料夾的資料庫已有的文章篇數。
網站掃描
已處理的網站項目數，包含讀取、比對、同批先前已核對和待查的項目。
無更新
本次已重讀並比對正文、推文和色碼，確認可保留原備份。
已更新
本次成功寫入本機資料庫的篇數，包含新增和更新。
待核色
「已更新」中配色未完全對齊的篇數，正文仍會出現在離線索引。備份資料夾的 color_line_check.txt 列出待核對的編號、AID 和行數。
處理明細
可查看待查、刪除、鎖定、站上無正文、配色待核對與保留舊備份的項目。站方明確顯示「此文章無內容」且安全回到看板後，會保留狀態並接續下一篇。已有的舊備份仍可閱讀。
離線 HTML
下載結束或手動停止後，程式核對匯出結果，只寫入新增、遺失或內容與導覽有變動的頁面。狀態區分別顯示總篇數與本次寫入篇數。完成後可點 index.html 路徑開啟。

首頁的「離線內容重整」用本機資料庫重新建立所有 HTML 和索引，可離線套用新版版面、更新鍵盤操作或補回遺失的 HTML。

每次下載的診斷紀錄集中在程式資料夾的 log 子目錄，依執行開始時間命名。紀錄包含要求與實際掃描範圍、登入與匯出耗時、逐篇查詢與讀取耗時、配色覆蓋率、續傳結果及錯誤位置。密碼、正文、登入畫面和例外原文不寫進診斷檔。

下載提醒

下載完成、中止、斷線、失敗或有項目待處理時，頁面右下角會顯示摘要。要在切換視窗或分頁時也收到提醒，點「啟用桌面通知」並允許瀏覽器權限，下載期間保留本機頁面開啟。可隨時點「停用桌面通知」。

離線鍵盤操作

列表每頁最多 20 篇，開啟後預設選在最新一篇。↑／↓ 選文，Enter 或 → 開啟，Page Up／Page Down 翻頁，Home／End 前往最舊／最新一篇。上方也有翻頁按鈕。

文章內 ↓ 往下捲一行，讀到底後再按會開啟較新一篇。→ 往下移動 22 行，讀到底後再按會回到列表。可開啟「22 行視窗」逐頁看手動翻頁的動畫。↑ 開啟較舊一篇，← 或 Esc 回到列表原位置。

ANSI 色彩怎麼轉成 HTML

程式在讀取文章時擷取終端前景色、背景色、亮色、反白和重設，逐行核對正文後用本機 CSS 顯示。游標跳過的空白維持背景色，文章刻意上色的空格會保留。未對上的行以文字顯示。雙色字、閃爍及進階色票仍有相容性限制。
